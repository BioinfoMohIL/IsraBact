What it does

One workflow, four independent gene sources

Each source is processed on its own. Skip the ones you don't need — the workflow only runs the tasks for inputs you actually provide.

abricate_results_tsvs

AbriCate — virulence

Virulence gene hits from AbriCate, matched on the GENE column.

amrfinder_amr_reports

AMRFinderPlus — resistance

Resistance genes only, from the AMRFinderPlus amr_report.

amrfinder_stress_reports

AMRFinderPlus — stress

Stress-response genes only, from the stress_report.

amrfinder_virulence_reports

AMRFinderPlus — virulence

Virulence genes only, from the virulence_report.

Inputs

4 inputs, all optional

Every input is an Array[File] — one report per strain. Provide any combination; omitted inputs are simply skipped.

InputSourceGene column used
abricate_results_tsvs AbriCate hits (virulence) GENE
amrfinder_amr_reports AMRFinderPlus amr_report Element symbol
amrfinder_stress_reports AMRFinderPlus stress_report Element symbol
amrfinder_virulence_reports AMRFinderPlus virulence_report Element symbol
ⓘ
How strains are identified: the strain name (the Key in every output) is taken from each file's name — everything before the first underscore. CA116948_amrfinder_amr_report.tsv becomes strain CA116948. Keep that naming convention when you export from Theiagen.
How to run

On Terra

Build a sample set

The workflow's inputs are Array[File], so they need a set, not individual samples. In Data, select the samples you want → Edit → Save selection as set.

Select your inputs

Go to Workflows and select wf_amr_gene_matrix. Double-check your set is selected, then map only the report columns you actually need — leave the rest blank.
